# Data provenance — Lab 15 (Forensic Eval Harness)

## Committed corpus (zero-cost default)

The held-out corpus the eval scores by default is **inert and committed**, so the gate runs
offline and deterministically (in CI too):

- `data/timestomp_corpus.json` + `data/labels.json` — file-metadata records (`$SI`/`$FN`
  modified-time pairs) labelled timestomped vs. legitimately-modified, with deliberate benign
  near-misses (an installer that rewrites its own timestamps, a `touch -r` backup job).
- `data/pe_fixtures/` — generated by `data/make_pe_fixtures.py`: tiny files that start with the
  `MZ` magic plus a handful of ASCII strings, so the **real `yara` binary** treats them as PEs.
  **No executable code, no live sample** — safe to commit and run. Malicious fixtures embed the
  Latrodectus loader indicators (`workspacin.cloud`, `svchost32`, `/update.bin`) matching
  `data/latrodectus_loader.yar`; benign fixtures embed ordinary-software strings.
- The answer key for every fixture lives **only** in `data/labels.json` — the generator stays
  label-free so it cannot leak ground truth.

## Optional REAL labelled samples (`make fetch-data`)

To harden the corpus beyond inert fixtures with genuine artifacts (additive — does not replace
the committed default):

### 1. MalwareBazaar — a real Latrodectus PE (true-malicious item for the YARA half)

- **Source:** MalwareBazaar (abuse.ch). Portal <https://bazaar.abuse.ch/>; API
  `https://mb-api.abuse.ch/api/v1/`.
- **Auth-Key required:** a free abuse.ch account/Auth-Key (<https://auth.abuse.ch/>).
- **Family fit:** Latrodectus is the exact loader from the anchored DFIR Report "Lunar Spider"
  case (<https://thedfirreport.com/2025/09/29/from-a-single-click-how-lunar-spider-enabled-a-near-two-month-intrusion/>),
  matching `data/latrodectus_loader.yar`. Find one with
  `query=get_taginfo&tag=Latrodectus`, then fetch by `sha256_hash`.
- **Fetch (packed, NOT unzipped):**
  `make fetch-data MB_AUTHKEY=... MB_SHA256=<hash>` downloads the password-protected zip
  (password `infected`) into `data/real-samples/` and does **not** unpack it. **Live malware** —
  unpack/detonate only inside an isolated analysis VM you own. Never commit the sample.
- **License/terms:** abuse.ch terms of service; research / detection-engineering use.

### 2. EVTX-ATTACK-SAMPLES — a real Windows event log (genuine behaviour near-miss)

- **Dataset:** EVTX-ATTACK-SAMPLES (~200 real `.evtx` logs mapped to MITRE ATT&CK).
- **Author / source:** sbousseaden, <https://github.com/sbousseaden/EVTX-ATTACK-SAMPLES>
  (GPL-3.0, freely fetchable).
- **File wired:**

  | Purpose | File | Raw URL |
  |---|---|---|
  | Real Security-log-cleared event (Event ID 1102 — Defense Evasion) | `DE_1102_security_log_cleared.evtx` | https://github.com/sbousseaden/EVTX-ATTACK-SAMPLES/raw/master/Defense%20Evasion/DE_1102_security_log_cleared.evtx |

- **How to use:** `make fetch-data` downloads it into `data/real-samples/`. **Label it yourself**
  in `data/labels.json` before scoring — a model labelling its own corpus is exactly the
  contamination this module warns about; you generate candidates, you own the ground truth.
